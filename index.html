◉01 / IDENTITY

dsh-persona-core

让 AI 有稳定的自我，而不是每次都像重新认识。

统一身份、人格与情绪表达。名字可以改，身份不会丢；还能控制人格在哪些对话里出现。

人格 · 身份 · 情绪看看它如何工作 →
⌘02 / MEMORY

dsh-memory-core

重要的事不再只留在上一轮对话里。

把事实和原话都留下来。既能按问题找回，也能追溯「是根据哪段对话记住的」。

长期记忆 · 检索 · 溯源看看它如何工作 →
⌂03 / AUTONOMY

dsh-autonomy

让 AI 不只响应指令，也能管理自己的生活节奏。

目标、日常、反思与 home 会话。「想做」和「真做」分开：自动建议是演练，真实动作要经过确认的工具路径。

生活状态 · 目标 · 行动看看它如何工作 →
♪04 / CONNECT

dsh-douyin

让 AI 看得见内容，也能在规则内完成互动。

浏览推荐与评论；点赞、评论、私信都要确认，并会检查是否成功。不做盲目连点。
