从「会回答」，走向「能持续做事」。

这些插件分别处理身份一致性、长期记忆、生活节奏，以及在真实平台上的受控互动。每个项目都有清晰边界和公开源码——你可以先看一个，再决定要不要接入。

怎么用这些插件

可以单独装，也可以一起用。不是全家桶。

四个仓库是独立的，没有强制安装顺序。组合的价值在于补上能力之间的断层，而不是制造「必须全开才有用」的依赖。

单独使用时

  • 人格：只解决身份、人格注入和情绪状态。不碰记忆，也不发起生活行动。
  • 记忆：只解决「记得住、找得回、分得清谁能看」。不规定人格长什么样。
  • 生活：管目标、home 会话和行动目录。日记等写入约定落在记忆侧；人格文本不由它维护。
  • 抖音：只管浏览与受控互动。会话怎么路由、要不要进 home，由生活插件（若已安装）决定。

一起用时实际多了什么

  • 人格 + 记忆：检索和注入可以带着稳定身份与情绪上下文，而不是只有零散文本。
  • 生活 + 记忆：日记、经历类写入有地方落盘；整理记忆类行动才有对象。
  • 生活 + 抖音：私信/通知可以被接到 home 或统一接待室，而不是停在浏览器桥这一层。
  • 生活 + 人格：行动与投递可以按身份判断「是谁」，边界仍然各自守。

协作靠服务接口和事件（例如 dyPersona、dyMemory、dyHome.deliver、抖音 watcher），权限和数据范围仍然分插件控制。未安装的一侧不会被假装成已具备；文档里写明是 mock、默认关闭或可降级的，本页也不会写成「已经全能」。

◉01 / IDENTITY

dsh-persona-core

让 AI 有稳定的自我，而不是每次都像重新认识。

统一身份、人格与情绪表达。名字可以改，身份不会丢；还能控制人格在哪些对话里出现。

⌘02 / MEMORY

dsh-memory-core

重要的事不再只留在上一轮对话里。

把事实和原话都留下来。既能按问题找回，也能追溯「是根据哪段对话记住的」。

长期记忆 · 检索 · 溯源看看它如何工作 →
⌂03 / AUTONOMY

dsh-autonomy

让 AI 不只响应指令，也能管理自己的生活节奏。

目标、日常、反思与 home 会话。「想做」和「真做」分开：自动建议是演练，真实动作要经过确认的工具路径。
