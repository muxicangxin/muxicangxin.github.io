04 独立仓库服务契约 dyPersona / dyMemory / dyHome可审查 边界写进文档
SCHEMATIC · DATA & CONTROL PATHS
可单独装四个仓库独立；没有强制全家桶。组合价值在减少断层，不在制造依赖。
边界写进代码注入白名单、scope 闸门、confirm 回读、pause 配额——文档和实现一致时才写进本页。
不把规划当现状mock 的自动执行、默认关闭的 inbox、可降级的 embedding，都会标明。

四块机制板

每块先给一句硬结论，再进详情看机制表、工具与边界。

01 / IDENTITY

dsh-persona-core

self_id 永不因改名而变。

身份轴、persona.md 版本、情绪规则状态、按会话的注入门。改名只动 name_version；群与子智能体默认不注入。

人格 · 注入 · 情绪看机制 →
02 / MEMORY

dsh-memory-core

事实一条线，原话一条线。

结构化 memories + 按天 raw 档案。关键词 / 语义 / 图谱三路 RRF，再过 owner·contact·public 闸门才注入。

检索 · 溯源 · scope看机制 →
03 / AUTONOMY

dsh-autonomy

建议不等于执行。

目标、home 轮换、行动配额、邮件与练习。自动 tick 是演练；真副作用只走工具路径。抖音主人进 home，其他人进总接待室。

节奏 · home · 门禁看机制 →
04 / CONNECT

dsh-douyin

写操作必须 confirm，并且回读。

CDP 桥、三 tab 隔离。浏览可宽，点赞评论私信必须确认与验证；私信限时效与日配额。
